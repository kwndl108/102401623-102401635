# 校园失物招领小程序（WEB 版）

第二次结对作业的程序实现。基于第一次结对作业的墨刀原型，用原生 HTML + CSS + JavaScript 实现"发布信息 — 浏览或搜索 — 查看详情 — 联系发布者 — 更新状态"的完整闭环。

## 一、目录结构说明

```
campus-lost-found/
├── index.html          # 程序入口页面（谷歌浏览器直接打开即可运行）
├── README.md           # 本说明文档
├── css/
│   └── style.css       # 全局样式（绿色主题，浅灰背景，卡片式布局）
├── js/
│   ├── store.js        # 数据层：种子数据、localStorage 持久化、物品增删改查、状态切换、计数
│   ├── utils.js        # 工具层：搜索过滤、表单校验、时间格式化、复制、图片压缩（纯函数，可单测）
│   └── app.js          # 视图层：hash 路由、五个页面渲染、弹窗/toast、交互事件
├── images/             # 物品示例图片（01-校园卡 ~ 06-高数课本，来自第一次作业原型）
└── test/
    ├── test.html       # 单元测试页面（谷歌浏览器直接打开即可运行）
    └── lib/            # 本地引入的测试框架 mocha.js / mocha.css / chai.min.js
```

依赖关系：`index.html` 按顺序加载 `store.js → utils.js → app.js`；测试页 `test/test.html` 只加载 `store.js` 与 `utils.js`（纯逻辑，不依赖页面 DOM）。

## 二、如何运行

### 1. 运行程序

1. 下载/克隆本项目全部文件到本地，保持目录结构不变；
2. **使用谷歌浏览器（Chrome）** 双击打开 `index.html`，即可开始使用，无需安装任何依赖、无需联网。

### 2. 运行单元测试

用谷歌浏览器打开 `test/test.html`，页面会自动运行全部单元测试（Mocha + Chai 已本地化，离线可跑）。所有用例通过时显示绿色"passing"。

## 三、功能说明

| 页面 | 功能 |
| --- | --- |
| 首页 | 顶部搜索栏、全部/寻物/招领筛选、双发布入口、信息列表（带图、状态、时间） |
| 发布页 | 寻物/招领切换、必填校验（漏填标红提示）、类别/地点快捷选择、图片上传（最多3张，自动压缩）、联系方式 |
| 搜索页 | 关键词搜索（匹配名称/描述/地点）、按类别/地点/状态筛选、最近搜索记录、无结果空态 |
| 详情页 | 物品大图、状态标签、信息卡、点击"联系发布者"显示联系方式并**一键复制**、浏览/联系计数 |
| 我的 | 我的发布列表、数据统计、编辑信息、标记"已找到/已归还"（可重新开放）、删除、重置数据 |

## 四、数据说明

- 首次打开自动写入 6 条示例信息（对应第一次作业原型），所有数据保存在浏览器 `localStorage` 中，刷新不丢失；
- 发布、编辑、标记状态、删除均为真实数据操作；
- 「我的」页提供"重置数据"按钮，一键恢复示例数据，方便测试人员反复体验。

## 五、附加特点

1. **一键复制联系方式**：详情页点击即可复制微信号/手机号到剪贴板；
2. **多维筛选**：搜索页支持按类别、地点、状态组合筛选；
3. **图片上传自动压缩**：选择图片后压缩为 base64 存储，不占服务器空间；
4. **浏览/联系计数**：统计每条信息的浏览量与联系人次数，帮助发布者判断热度；
5. **表单友好校验**：漏填必填项即时标红提示，不打断填写流程。
